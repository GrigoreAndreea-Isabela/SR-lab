# Descrierea setului de date

### Nume: Amazon_BestSelling_Books_500.csv
### Kaggle link: https://www.kaggle.com/datasets/shambhurajejagadale/amazon-bestselling-books-dataset-500-books
### Descriere
Setul contine informatii despre 500 de carti bestseller din platforma Amazon si este realizat relativ recent (acum 5 luni). 
Printre atribute se numara: Titlul cartii (string), Autorul (string), Categoria (string), Pretul (double),
Rating-ul (double), Anul Publicarii (int) si numarul de saptamani pentru care cartea a fost considerata bestseller (int).

Am ales acest set de date deoarece il consider potrivit pentru analiza factorilor care caracterizeaza cartile de succes.
Putem vedea, de exemplu, daca exista o legatura intre rating, pret si perioada in care o carte a ramas bestseller 
sau daca anumite categorii de carti sunt mai reprezentate in topul bestsellerelor.
Aceste informatii pot fi folosite ulterior pentru identificarea unor tipare, dar si pentru formularea unor recomandari de carti.
